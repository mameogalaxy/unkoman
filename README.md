# うんこマン -UNKOMAN-

うんこなげゲー 💩

スマホで指をグルグル「グリグリ」回してウンコの先っぽを回転させ、いきおいをためて遠くへ投げ飛ばすゲームです。砲丸投げ／バッターのような手前から奥への視点で、どこまで飛ばせるかを競います。

## 遊び方

1. 「ウンコをにぎる」をタップ
2. 画面のウンコを指で **グリグリ回転** させていきおいをためる（弾力でビヨ〜ンと伸びます）
3. いきおいゲージがたまったら **指をはなす** と発射！
4. ウンコが回転しながら奥へ飛んでいき、着地点で **飛距離** が決まります
5. 距離に応じて「ナイスウンコ！！」などのかけ声＆エフェクト。最高記録に挑戦！

## 特徴

- グリグリ回転で勢いをためる直感操作（タッチ・マウス対応）
- 砲丸投げ／バッター視点の擬似3D遠投表現
- 飛んでいくウンコの軌跡・スピードライン・着地スプラッシュ
- 「ナイスウンコ！！」「神ウンコ！！！」などのかけ声（音声合成・効果音つき）
- 最高記録をブラウザに保存

## 起動方法

`index.html` をブラウザで開くだけ（インストール不要）。スマホで開けばタッチ操作で遊べます。

```
open index.html
```

GitHub Pages などで公開すればスマホからURLでそのまま遊べます。
