# ⏱️ タイムラプスカメラ

カメラ映像を一定間隔でキャプチャし、タイムラプス動画（WebM）として書き出すブラウザアプリです。
ビルド不要・依存ライブラリなしのバニラ HTML/CSS/JS で、すべての処理がブラウザ内で完結します（映像は外部に送信されません）。

## 使い方

カメラ API は `https` またはローカルサーバー経由でのみ動作します（`file://` 直開きではカメラが許可されません）。

ローカルサーバーで開く例:

```bash
cd timelapse
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

1. **📷 カメラを開始** を押してカメラを許可します。
2. **撮影間隔**（秒/分ごと）と**再生フレームレート (fps)** を設定します。
3. **● 撮影開始** で、指定間隔ごとに1フレームずつ撮影します。
4. **■ 撮影停止** で停止します。撮影は再開できます。
5. **▶ プレビュー再生** で出来上がりを確認できます。
6. **⬇ 動画を書き出し** で `.webm` ファイルをダウンロードします。

## スマホで使う

iPhone(Safari) / Android(Chrome) のブラウザでそのまま動きます（背面カメラ優先）。
ただしカメラは **https 経由**でしか許可されないため、スマホでは GitHub Pages 等に公開して開くのが簡単です。

- 撮影中は **Wake Lock API** で画面スリープを防ぎます（長時間タイムラプスでも撮影が止まりません）。
- 省電力でブラウザがバックグラウンドに回ると撮影が止まることがあるため、撮影中はこの画面を開いたままにしてください。

### GitHub Pages で公開する例

リポジトリの Settings → Pages で公開ブランチを指定すると、
`https://<ユーザー名>.github.io/unkoman/timelapse/` のように開けます。

## 機能

- 撮影間隔の指定（秒 / 分）
- 再生フレームレート (1〜60 fps) の調整
- 複数カメラの切り替え
- タイムスタンプの焼き込み（任意）
- 撮影フレーム数・想定再生時間・実撮影時間のサマリー表示
- WebM (VP9/VP8) での動画書き出し

## 動作要件

- `getUserMedia` / `MediaRecorder` / `canvas.captureStream` / `createImageBitmap` に対応したモダンブラウザ
  （Chrome, Edge, Firefox など）

## ファイル構成

- `index.html` … 画面構造
- `style.css` … スタイル
- `app.js` … 撮影・再生・書き出しロジック
